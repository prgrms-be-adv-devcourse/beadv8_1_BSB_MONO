# 정책 질문

정책·용어 질문에는 레포 문서가 유일한 근거입니다. 기억이나 추측으로 답하지 않습니다.

## 순서

1. 아래 순서로 찾습니다. 답을 찾으면 멈춥니다.
   1. `CONTEXT.md`: 용어의 뜻, 피할 말, 코드 이름
   2. `docs/policy/NN-*.md`: 장별 정책. 번호 표기는 `docs/policy/README.md`
   3. `docs/policy/questions.md`: 이미 물어본 질문과 결정
   4. 관련 코드 주석의 「정책 N장 M-K」: 번호로 1~2번의 해당 항을 다시 확인
2. 답에 출처를 붙입니다. 예: `docs/policy/04-장바구니결제.md` 2-3. 1차와 2차가 다르면 둘 다 적습니다.
3. 항 본문이 `(회의 후 채움)`이거나 문서에 없으면 **정해지지 않음**이라고 답합니다. 비슷한 정책에서 짐작한 내용은 답으로 쓰지 않습니다. 이어서 `questions.md`에 넣을 한 줄 초안을 보여 줍니다.

## 답 쓰는 법

- 상태값 영어와 코드 이름 대신 뜻으로 씁니다.
- "→ 그래서 무슨 일이 생기는지"까지 씁니다.
- 비유와 번역체는 쓰지 않습니다.

## 질문 로그 초안

`questions.md` 표의 열 순서로 한 줄을 만듭니다. 파일은 사용자가 확인한 뒤에 고칩니다.

```
| 날짜 | 질문 | 정책 N장 M-K | 물어본 사람 | (비움) | (비움) | | |
```

돈·인증·잠금 관련이면 "회의로 정할 것"이라고 함께 알립니다.
