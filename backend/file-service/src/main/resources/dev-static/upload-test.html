파일 업로드 테스트

① 업로드 URL 발급 → ② 브라우저가 S3에 직접 PUT → ③ 업로드 완료 확인(UPLOADED) → ④ 대상에 연결(ACTIVE) → ⑤ 조회 순서로 확인합니다. (개발용 페이지)

1. 업로드 (①~③)

끄면 ②·③ 버튼을 직접 누릅니다

2. 대상에 연결 (④, 내부 API)

PUT /internal/v1/file/refs/{refType}/{refId}/files — 실제로는 product-service가 대회를 저장할 때 부릅니다. 체크한 파일 목록이 그 대상의 파일 전체가 되고, 목록에서 빠진 기존 파일은 DELETED가 됩니다.

연결파일 ID파일명보낼 용도 (fileType)순서 (sortNo)상태

3. 조회 (⑤)

GET /api/v1/file/files?refType=&refId= — 연결된(ACTIVE) 파일만 용도 → 순서 순으로 나옵니다. 회원 헤더 없음.

GET /api/v1/file/files/{fileId} — 연결된 파일은 누구나, 연결 전 파일은 올린 회원만 볼 수 있습니다.
