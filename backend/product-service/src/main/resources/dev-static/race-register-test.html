대회 등록 테스트

등록 요청에 어떤 값이 들어가는지 확인하는 개발용 페이지입니다. 칸을 채우면 아래 요청 JSON이 바로 바뀝니다. 등록 API는 아직 없어서 요청을 보내지 않습니다. 검사 규칙은 칸 아래 안내로만 적었습니다(실제 검사는 등록 API에서 합니다).

판매자

요청 헤더 X-Member-Id로 보냅니다. 승인된 판매자 복제본(PRODUCT_SELLER, APPROVED)이 있는 회원이어야 합니다.

대회 정보

판매 시작 일시(sale_open_at)는 입력하지 않습니다. 크루 예매 시작·개인 예매 오픈 중 이른 시각으로 서버가 채웁니다.

종목 · 참가권

참가비는 0원으로 등록할 수 없습니다. 최소 나이는 만 14세 이상이고(대회 당일 만 나이), 최대 나이를 비우면 상한이 없습니다.

종목명구분노면 거리(km)제한 시간(분)참가비 키트 포함키트 금액최소 나이최대 나이 크루 몫 정원개인 몫 정원

이미지

이미지는 file-service 업로드 페이지(8083)에서 올리고(업로드 완료까지), 받은 fileId를 적습니다. 올린 파일은 1일 안에 대회에 연결해야 정리 배치가 지우지 않습니다. 대표 이미지 1장은 꼭 있어야 합니다.
