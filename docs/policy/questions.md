# 정책 질문 로그

1. Claude나 팀원이 문서에서 답을 못 찾으면 아래 표에 한 줄을 남깁니다.
2. 돈·인증·잠금과 관련된 질문은 회의에서 정하고, 나머지는 담당자가 정해서 기록합니다.
3. 정해지면 `결정` 칸을 채우고, 해당 정책 파일(`docs/policy/NN-*.md`)에 반영한 뒤 `반영한 곳`에 적습니다.

|---|---|---|---|---|---|---|---|
| 10/30 | 대회가 취소될 때 결제 대기 주문([결제하기]로 자리를 잡고 아직 결제 전, 길어야 15분)을 어떻게 끝내는지. ① 지금처럼 결제만 막아 두면 결제 기한이 지날 때까지 구매자 화면에 결제 대기로 보이고, [결제]를 누르면 거절 메시지를 받는다 ② 바로 취소로 닫으면 화면이 곧바로 "대회 취소"로 바뀐다 | 정책 5장 4-1~4-4(대회 변경, 비어 있음), 정책 4장 2-1~2-6(결제, 비어 있음) | 이다윗 | | | | |
