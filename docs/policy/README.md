# 정책

**원본은 피그잼 아이디에이션 보드 1페이지**입니다. 이 폴더의 `01-*.md` ~ `10-*.md`는 지훈이 피그마 MCP로 옮겨 적은 **복사본**입니다. 팀원의 Claude는 이 복사본을 읽고 답합니다.

## 고치는 순서

1. 피그잼 원본을 먼저 고칩니다.
2. 복사본을 PR로 갱신합니다. 파일 머리말의 `복사일`도 같이 바꿉니다.
3. 복사본이 원본과 다르면 원본을 따릅니다.

정책 질문과 결정은 [questions.md](questions.md)에 남깁니다.

## 번호 표기 규칙

코드 주석과 문서에서 정책을 가리킬 때는 **「정책 N장 M-K」** 한 가지로 씁니다. 예: 「정책 4장 2-3」은 4장 파일의 `### 2-3` 항입니다.

- N은 장 번호, M은 장 안의 묶음 번호(피그잼의 가로 한 줄), K는 묶음 안의 항 번호입니다.
- 번호는 해당 장 파일의 `## M. 묶음 이름` 과 `### M-K` 제목과 같습니다. 파일을 열면 같은 번호가 있어야 합니다.
- 2차 항목은 번호 앞에 「2차」를 붙입니다. 예: 「정책 4장 2차 2-1」. 1~7장 파일에는 1차와 2차 구역이 따로 있습니다.
- 「피그잼 정책 1차 5장」, 「payout.md 4-3」 같은 옛 표기는 쓰지 않습니다. 옛 표기를 만나면 새 표기로 고칩니다. 기존 코드 주석은 따로 일괄 정리합니다.

> 지금 파일의 번호와 묶음 이름은 피그잼의 구조(묶음 순서, 묶음 안 항 개수)에서 따왔고, 항 본문은 아직 읽지 않았습니다. 지훈이 본문을 복사할 때 피그잼에 적힌 번호와 맞는지 확인하고, 다르면 이 파일의 번호를 피그잼에 맞춥니다.
