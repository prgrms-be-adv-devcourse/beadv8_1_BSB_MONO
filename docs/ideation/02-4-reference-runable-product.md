- 작성일: 2026-10-05
- 대상: [러너블 쿠키RUN 5K 2인권 상품](https://runable.me/product/20969?comp=19600) + 팀원이 공유한 신청 화면 캡처 3장 (비상 연락처 입력, 참가자 카드, 결제 제한시간)
- 조사 방법: 상품 페이지 직접 확인. '대회 신청 하기'는 로그인이 필요해 신청 화면 안쪽은 캡처로만 봤다.
- 표기: **[사실]** 화면에서 확인 / **[추론]** 사실에서 끌어낸 해석 / **[결정 필요]** 우리가 정해야 함
- 회사·단체 접수 분석은 [02-1 러너블](02-1-competitor-runable.md)에 있다. 이 문서는 화면과 데이터만 본다.

## 0. 핵심 결론

1. **대회 1개 아래 상품이 여러 개다.** 같은 대회(`comp=19600`)에 10K, 5K 1인권, 5K 2인권(추가접수)이 각각 상품으로 올라 있다. 우리도 `대회 : 상품 = 1 : N`으로 잡는다.
2. **기한이 셋이다.** 접수 기간, 정보 수정 기한, 참가 취소 기한을 따로 보여 준다. 크루 접수에서는 크루원마다 결제 시점이 달라서 이 세 기한이 더 중요하다.
3. **참가자 카드 UI는 크루 접수에 그대로 쓸 수 있다.** 러너블은 2인권의 2명을 카드로 나눴다. 우리는 크루원 N명을 카드로 나누고 결제 상태만 더하면 된다.
4. **결제 제한시간(10분 안팎)은 정원 임시 확보 장치다.** 크루원이 각자 결제하는 우리 구조에서는 "크루 몫을 언제까지 잡아 둘지"를 따로 정해야 한다.

## 2. 신청 화면 캡처 [사실]

### 2-1. 참가자 카드 (접이식)

- 머리: `옥지훈 님` + 회색 배지 `내 정보` (구매자 본인 카드라는 표시) [추론]
- 요약 줄: `5K | 5. XL / M (250~275mm) / 70,000원` → **종목 | 옵션 1 / 옵션 2 / 1인 금액**
  - 옵션 1은 티셔츠 사이즈, 옵션 2는 발 크기 범위로 보아 양말 사이즈 [추론]
  - 2인권 140,000원이 카드에서는 1인 70,000원으로 나뉘어 있다 → 묶음 상품도 참가자 단위로 금액을 쪼갠다
- 오른쪽 위 접기/펴기 화살표. 펼치면 그 참가자의 입력 폼이 나온다 [추론]

### 2-2. 비상 연락처

- 섹션 제목 `비상 연락처`
- `비상연락처 이름*` (예: 홍길동), `비상연락처 전화번호*` (예: 01012345678, 하이픈 없이)
- 둘 다 필수

### 2-3. 결제 제한시간

- 연한 코발트 띠: `시간 내에 결제를 완료해 주세요` + 시계 아이콘 + `09:35` 카운트다운
- 10분에서 줄어드는 것으로 보인다 [추론]. 시간이 지나면 확보한 자리를 푸는 것으로 보인다 [추론]

## 4. 정해야 할 것 [결정 필요]

1. **결제 제한시간 길이와 범위.** 개인 결제 10분 확보만 둘지, 크루 몫 전체를 크루장이 신청한 때부터 며칠 잡아 둘지. 둘을 함께 쓰면 "크루 몫 확보 기한(일 단위) + 개인 결제 확보(분 단위)" 두 겹이 된다.
2. **정보 수정 · 취소 기한을 크루원에게 어떻게 보여 줄지.** 기한이 지나기 전에 아직 결제 안 한 크루원에게 알림을 보낼지.
3. ~~묶음 상품(2인권)을 받을지~~ → 정책 1-3-2(참가권은 본인 것만 1장)로 이미 정해져 있다. 받지 않는다.
4. **미성년 참가자.** 보호자를 같은 크루의 성인 크루원으로 연결할지, 정보만 받을지.
5. **옵션 사이즈 변경.** 정보 수정 기한 안이면 사이즈도 바꿀 수 있게 할지 (재고 연동 여부).
6. ~~상세 정보 입력 방식~~ → 상세 소개는 판매자가 올리는 자유 형식. 정해진 항목만 입력 칸 (정책 2-1-7).

## 5. 확인하지 못한 것

- 신청 화면 전체 순서(약관 동의, 결제 수단, 완료 화면) — 로그인 필요
- 결제 시간이 끝났을 때 실제 동작
- 참가자 입력 폼의 비상 연락처 외 필드
- 상세 이미지 내용 — 판매자가 올리는 영역이라 확인하지 않아도 된다
